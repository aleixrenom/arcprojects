## Overview

Portfolio website for Aleix Renom Cisa with two content streams: apps and projects. The current UI has one Apps page and one Projects page, each showing a card grid, plus a full-screen detail view opened from a card. You move between pages by clicking the vertical separator on the left (for the Projects page) or right (for the Apps page) edge of the screen.

See `Design/DESIGN.md` for the full design spec.

## Tech Stack

- React + TypeScript + Vite
- Zustand for global state
- TanStack Router with hash history (`#/app/<id>`, `#/project/<id>`) for shareable detail-page URLs; works on any static host without server config
- CSS custom properties for theming
- The project may use the Motion library for animation work in a future task; do not add animation dependencies in the current task unless the user explicitly requests them.

## Architecture

- `src/router.tsx` — route tree (`/`, `/app/$appId`, `/project/$projectId`), hash history, theme root; the URL is the source of truth for which detail page is open
- `src/App.tsx` — index-route component: page grids, carousel, separator
- `src/data/cards.ts` — central card metadata (`apps`, `projects`, `findCard()`)
- `src/store/ui.ts` — `theme`, `activePage`
- `src/pages/AppsPage.tsx` / `ProjectsPage.tsx` — card grids, navigate to detail routes
- `src/pages/DetailPage.tsx` — full-screen detail page (hosts app components)
- `src/index.css` — global theme and interaction styles
